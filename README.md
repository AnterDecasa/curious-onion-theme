# Curious Onion Theme

A custom WordPress block theme for the Curious Onion personal blog.

## About the Project

Curious Onion Theme is a custom WordPress block theme designed like a digital scrapbook, journal, and commonplace book. The project explores how a personal blog can feel organic, expressive, and handmade while still being responsive, accessible, and built using modern WordPress theme development practices.

## Project Status

🚧 In development. This theme is being built from scratch as a learning project while documenting the process of designing and developing a custom WordPress block theme.
